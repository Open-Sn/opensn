    "# Material Source Selected by Block ID\n",
    "\n",
    "This tutorial applies a volumetric source to every cell carrying a selected mesh block ID. This form is useful when a source occupies an entire material region."
   ]
  },
  {
   "cell_type": "markdown",
   "id": "define",
   "metadata": {},
   "source": [
    "## Build the mesh and source block\n",
    "\n",
    "The slab is two centimeters long. Cells in its left half are assigned block ID 1, while the remaining cells retain block ID 0. `VolumetricSource(block_ids=[1], ...)` then activates the source only in the block-1 cells. Both blocks use the same material so the example isolates source selection from material effects."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "setup",
   "metadata": {},
   "outputs": [],
   "source": [
    "from mpi4py import MPI\n",
    "from pyopensn.aquad import GLProductQuadrature1DSlab\n",
    "from pyopensn.context import Finalize\n",
    "from pyopensn.logvol import RPPLogicalVolume\n",
    "from pyopensn.mesh import OrthogonalMeshGenerator\n",
    "from pyopensn.solver import DiscreteOrdinatesProblem, SteadyStateSourceSolver\n",
    "from pyopensn.source import VolumetricSource\n",
    "from pyopensn.xs import MultiGroupXS\n",
    "\n",
    "rank = MPI.COMM_WORLD.rank\n",
    "nodes = [i / 20.0 for i in range(41)]\n",
    "mesh = OrthogonalMeshGenerator(node_sets=[nodes]).Execute()\n",
    "mesh.SetUniformBlockID(0)\n",
    "\n",
    "source_block = RPPLogicalVolume(infx=True, infy=True, zmin=0.0, zmax=1.0)\n",
    "mesh.SetBlockIDFromLogicalVolume(source_block, 1, True)\n",
    "\n",
    "xs = MultiGroupXS()\n",
    "xs.CreateSimpleOneGroup(sigma_t=1.0, c=0.0)\n",
    "quadrature = GLProductQuadrature1DSlab(n_polar=16, scattering_order=0)"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "source-heading",
   "metadata": {},
   "source": [
    "## Define the source\n",
    "\n",
    "The complete source definition is the block selection and one strength value for each energy group."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "source",
   "metadata": {},
   "outputs": [],
   "source": [
    "source = VolumetricSource(block_ids=[1], group_strength=[1.0])"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "solve-heading",
   "metadata": {},
   "source": [
    "## Configure and solve the problem"
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "solve",
   "metadata": {},
   "outputs": [],
   "source": [
    "problem = DiscreteOrdinatesProblem(\n",
    "    mesh=mesh,\n",
    "    num_groups=1,\n",
    "    groupsets=[\n",
    "        {\n",
    "            \"groups_from_to\": (0, 0),\n",
    "            \"angular_quadrature\": quadrature,\n",
    "            \"inner_linear_method\": \"petsc_gmres\",\n",
    "            \"l_abs_tol\": 1.0e-10,\n",
    "            \"l_max_its\": 100,\n",
    "        }\n",
    "    ],\n",
    "    xs_map=[{\"block_ids\": [0, 1], \"xs\": xs}],\n",
    "    volumetric_sources=[source],\n",
    "    boundary_conditions=[\n",
    "        {\"name\": \"zmin\", \"type\": \"reflecting\"},\n",
    "        {\"name\": \"zmax\", \"type\": \"reflecting\"},\n",
    "    ],\n",
    ")\n",
    "solver = SteadyStateSourceSolver(problem=problem, compute_balance=True)\n",
    "solver.Initialize()\n",
    "solver.Execute()"
   ]
  },
  {
   "cell_type": "markdown",
   "id": "verify",
   "metadata": {},
   "source": [
    "## Verify the selected source region\n",
    "\n",
    "The active block has unit length and a source strength of one, giving a total production rate of one. With reflecting boundaries and pure absorption, the absorption rate must also be one."
   ]
  },
  {
   "cell_type": "code",
   "execution_count": null,
   "id": "check",
   "metadata": {},
   "outputs": [],
   "source": [
    "balance = solver.ComputeBalanceTable()\n",
    "production = balance[\"production_rate\"]\n",
    "absorption = balance[\"absorption_rate\"]\n",
    "balance_error = abs(production - absorption)\n",
    "if rank == 0:\n",
    "    print(f\"Block-source production rate={production:.8e}\")\n",
    "    print(f\"Block-source absorption rate={absorption:.8e}\")\n",
    "    print(f\"Block-source balance error={balance_error:.8e}\")\n",
    "assert abs(production - 1.0) < 1.0e-8\n",
    "assert balance_error < 1.0e-8\n",
    "if \"opensn_console\" not in globals():\n",
