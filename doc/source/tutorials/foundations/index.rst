===========
Foundations
===========

This section introduces the common structure of an OpenSn calculation. These tutorials assume
familiarity with Python, but no previous experience with OpenSn or deterministic transport.

Start here
----------

The tutorials are intended to be completed in order:

.. toctree::
   :maxdepth: 1

   opensn_input_anatomy
   first_1d_fixed_source
   first_2d_fixed_source
   running_serial_and_parallel

The two calculation notebooks use small, deterministic problems that run in serial and include
quantitative checks. The input-anatomy and execution tutorials explain the common model structure
and supported serial and parallel launch modes.
