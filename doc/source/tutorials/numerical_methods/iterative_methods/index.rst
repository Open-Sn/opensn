Iterative Methods
=================

These tutorials examine how groupset solver choices affect the route to a converged transport
solution. They hold the physical model fixed so differences in iteration behavior can be separated
from changes in the underlying problem.

See the :doc:`iterative-methods reference </userguide/iterative_methods>` for all available methods
and convergence controls.
