Acceleration
============

Acceleration tutorials introduce low-order corrections that reduce slowly converging transport
error modes. Each example compares the accelerated solution with a baseline solve so the effect on
convergence is separated from the final physical result. The
:doc:`CMFD tutorials <../cmfd/index>` study the CMFD options on the C5G7 benchmark core.
