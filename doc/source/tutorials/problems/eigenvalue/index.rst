Eigenvalue Problems
===================

These tutorials build neutron multiplication problems in which OpenSn solves for the dominant
eigenvalue and its associated flux distribution. The example covers a multigroup reactor pin cell.
The :doc:`CMFD tutorials <../../numerical_methods/cmfd/index>` accelerate eigenvalue solves of the
C5G7 benchmark core.
