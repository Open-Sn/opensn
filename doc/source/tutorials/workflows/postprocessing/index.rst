Postprocessing
==============

Postprocessing tutorials turn transport solutions into scalar quantities suitable for analysis,
comparison, and reporting. The examples cover regional reaction rates, cross-section sensitivity,
boundary leakage, and exporting transport solutions for use by external programs.

See the :doc:`postprocessor reference </userguide/post_processors>` for other supported reductions
and response multipliers.
