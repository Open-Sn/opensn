Meshing and Partitioning
========================

These tutorials cover the mesh generators and partitioning options used to define an OpenSn
computational domain. The examples progress from orthogonal meshes to imported Gmsh, OBJ, and VTU
meshes, mesh extrusion, block-ID assignment, and parallel partition layouts.
