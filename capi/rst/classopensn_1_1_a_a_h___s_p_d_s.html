AAH_SPDS(int id, const Vector3 &omega, std::shared_ptr<MeshContinuum> grid, const SPDSFaceNeighborInfoVec &face_neighbor_info, bool allow_cycles, bool use_gpus = false)

Creates a sweep-plane data structure (SPDS) for the given direction and grid.

Parameters:

  • id – The unique identifier for this SPDS.

  • omega – The angular direction for the sweep operation.

  • grid – The grid on which the sweep is performed.

  • face_neighbor_info – Cached neighbor information for every local cell face.

  • allow_cycles – Whether cycles are allowed in the local and global sweep dependency graphs.

  • use_gpus – Whether to allocate device memory for GPU acceleration.
