class ResponseEvaluator

A class used for evaluating responses by folding sources against adjoint solutions.

The workflow for this utility is constructed to minimize the file reading necessary for evaluations. To begin, one should add all adjoint solutions that are desired for response computations as named data sets. Then, one should define the different forward source configurations of interest. With this, the user can now iterate over the source configurations and convolve them against all available adjoint data sets. For example, 

evaluator = ResponseEvaluator(problem=phys)
evaluator.SetOptions(data=[{"name": "detector", "file_prefixes": {...}}, ...])

responses = {}
for config_index, source_config in enumerate(source_configs):
    evaluator.ClearForwardSources()
    evaluator.SetOptions(sources=source_config)

    responses[config_index] = {
        data_name: evaluator.EvaluateResponse(data_name)
        for data_name in data_names
    }

Add a named data set.

file_prefixes may contain flux_moments and angular_fluxes, the adjoint flux moments and angular fluxes that EvaluateResponse folds against the forward sources, and surface_angular_fluxes, the surface data that EvaluateSurfaceResponse pairs. Flux moments and angular fluxes must have been written with the current partitioning. The listed surfaces are read from all surface files of the prefix, whatever number of ranks and partitioning wrote them, and distributed by face over the current ranks with DistributeSurfaceAngularFluxes. Each is a boundary name or an interior surface name, which reads both stored sides <name>_u and <name>_d. Collective.

double EvaluateResponse(const std::string &data_name) const

Evaluate a response by folding the currently defined forward sources against the adjoint flux moments and angular fluxes of the named data set added with SetDataOptions.

Collective. Throws std::invalid_argument for an unknown data set and std::logic_error if the data set lacks the flux moments or angular fluxes that the defined sources require.

std::vector<SurfaceResponse> EvaluateSurfaceResponse(const std::string &fwd_data_name, const std::string &adj_data_name, const std::vector<std::string> &surfaces = {}) const

Evaluate the surface response of forward and adjoint surface angular fluxes added with SetDataOptions.

Returns one surface response per selected surface, as defined in ComputeSurfaceResponses: its outgoing and incoming parts and their sum, the response carried across the surface. They are also logged at verbosity 1.

Collective. Throws std::invalid_argument for unknown data sets or surfaces, a surface requested more than once, and incompatible data, and std::logic_error if the forward and adjoint data do not cover the same faces.

Parameters:

  • fwd_data_name – Name of the forward data set.

  • adj_data_name – Name of the adjoint data set.

  • surfaces – Surfaces to evaluate: boundary names and interior surface names (<name> or <name>_u along the _u normal, <name>_d along the _d normal). If empty, every surface in the forward data is evaluated, in name order.
