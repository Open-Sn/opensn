class DiscreteOrdinatesSolver : public opensn::Solver

Base class for solvers that drive a DiscreteOrdinatesProblem.

Solution and time state remain in the shared problem. A solver restores its temporary settings before returning. Validation is collective.

Subclassed by opensn::NonLinearKEigenSolver, opensn::PowerIterationKEigenSolver, opensn::SteadyStateSourceSolver, opensn::TransientSolver
