class AAHD_AngleSet : public opensn::AngleSet

AAHD angle set.

Fused all-at-once batch interface

Used only by SweepScheduler::ScheduleAlgoAAOFused.

A batch run sweeps every level of every member angle set in one uninterrupted sequence of launches on one stream. No per-level progress is kept between calls. See AAHDSweepChunk::SubmitBatchRun.

Prepare this angle set’s device buffers for a batch run.

Return the number of levels in this angle set’s levelized local subgrid.

void FillBatchSlots(std::size_t num_levels, std::size_t slot_stride, gpu_kernel::AAHD_BatchSlot *slots) const

Write this angle set’s batch slot for each level of a batch run.

Levels at or beyond NumLevels() get an empty slot because every batch member runs through the same level range.

Parameters:

  • num_levels – Number of levels in the batch run.

  • slot_stride – Distance between this angle set’s slots of consecutive levels.

  • slots – Slot array. The slot for level level is written to slots[level * slot_stride].

void SubmitCompletionCopies()

Enqueue this angle set’s post-sweep device-to-host copies without synchronizing.

The copies go on the angle set’s FLUDS stream, which is its run’s lane. The caller waits for that stream before FinishCompletion.

void FinishCompletion(SweepChunk &sweep_chunk)

Finish this angle set after its SubmitCompletionCopies copies have completed.

This decrements the followers’ dependency counters, sends the downstream angular fluxes, and copies the saved angular flux to its destination. It mirrors the second part of AngleSetAdvance.

Parameters:

sweep_chunk – Sweep chunk that ran the batch.
