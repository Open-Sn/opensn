static void ReadFluxMoments(LBSProblem &lbs_problem, const std::string &file_base, bool single_file, std::optional<std::reference_wrapper<std::vector<double>>> opt_dest = std::nullopt, FluxSolutionRole expected_role = FluxSolutionRole::UNSPECIFIED, AdjointFluxOrientation expected_orientation = AdjointFluxOrientation::UNSPECIFIED)

Read a flux moments vector from a file.

The file must have been written with the same rank count and partition. Collective: a file that cannot be read or does not match the problem raises an error on every rank, and the destination is left unchanged.

Parameters:

  • lbs_problem – LBS problem

  • file_base – File name base

  • single_file – Read the single file <file_base>.h5 instead of the per-rank file <file_base><rank>.h5. Serial runs only: throws std::invalid_argument on every rank of a multi-rank run, before any file is opened.

  • opt_dest – Optional destination vector to populate instead of the problem-owned flux moments.

  • expected_role – Required solution role, or unspecified to accept any role.

  • expected_orientation – Required adjoint orientation, or unspecified to accept any.

Reads and validates the “mesh” group of a flux-moment or angular-flux file.

Every file cell must be a distinct local cell whose nodes match the file node locations one to one, and the dataset sizes must match the metadata. Throws on the calling rank only.
