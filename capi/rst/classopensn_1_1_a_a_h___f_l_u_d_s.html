virtual void CorrectNewDelayedAngularFlux(const DelayedFluxCorrection &correction) override

Adds an isotropic nodal correction to every new (latest-iterate) delayed angular flux, that is, to the lagged values the next sweep reads where a cyclic dependency was broken, within this location or between locations.

The correction is evaluated at the face node of the downwind cell that reads the value.

A FLUDS type that stores delayed angular fluxes must override this. The default accepts only a FLUDS without them and otherwise throws, so that lagged fluxes of a type that does not implement the correction fail loudly instead of keeping an error that re-enters on the next sweep.

virtual void TallyDelayedIncomingCurrent(const AngularQuadrature &quadrature, const std::vector<std::uint32_t> &angle_indices, bool subtract_old, const DelayedCurrentTally &tally) const override

Passes to tally, for every incoming face node of a cell that reads delayed angular fluxes (a cyclic dependency broken within this location or between locations) and every groupset group, the inward partial current \( -\sum_n w_n (\Omega_n \cdot \hat{n}) \delta\psi_n \) of those fluxes over the directions of this FLUDS, with \(\hat{n}\) the outward normal of the face of the reading cell.

angle_indices are the directions of quadrature held by this FLUDS, in its storage order. \(\delta\psi_n\) is the new delayed value minus the old one when subtract_old is true (after a sweep: the change of the upwind flux that the sweep did not see) and the new delayed value otherwise.

A FLUDS type that stores delayed angular fluxes must override this. The default accepts only a FLUDS without them and otherwise throws.
