class AAHCellSweepData

Contiguous copies of the local cell data that the CPU AAH sweep kernels read.

On an unstructured mesh every angle set holds one direction, so a sweep visits each cell once per direction and reads its data from memory each time. Reading it from a few contiguous arrays instead of the cell, its mapping, and its unit matrices, which are separate heap objects, takes fewer memory accesses. The data depends only on the mesh and the discretization, so the problem builds it once and every groupset shares it. The values are copies of the unit cell matrices, so the kernels compute exactly what they computed from the originals.

Builds the data of every local cell.

The flux moments of a node are num_moments times num_groups values, so a cell’s first node is its phi address divided by that product.
