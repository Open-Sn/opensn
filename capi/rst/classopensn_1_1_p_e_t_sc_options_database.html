class PETScOptionsDatabase

PETSc options that belong to one solver.

Options inserted into the global database stay there and reach every later solver whose prefix they carry, such as the diffusion solvers of the other groupsets of a problem, which share one prefix, or the solvers of a later problem with the same name. The options held here are in the global database only while a Scope of this object exists, so the solver creates one around each of its PETSc calls that read options. Objects that PETSc creates inside those calls, such as the blocks of a block Jacobi preconditioner and direct solver packages, read the options too.

class Scope

Puts the options of a database into the global database and, when destroyed, restores the values that those options had in the global database before.

The options therefore take precedence over those of PETSC_OPTIONS and the .petscrc files, which apply to every solver. Scopes must be destroyed in the reverse order of their creation.
