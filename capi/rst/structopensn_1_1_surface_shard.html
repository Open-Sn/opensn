struct SurfaceShard

The faces of one stored surface tag that are owned by this rank.

A face is owned by rank SurfaceFaceOwner(key, P), where key is its centroid key, so every data set read on the same communicator places a given physical face, from either side of an interior surface, on the same rank. Faces are stored in arrival order; index gives the local face index of each key in key order.
