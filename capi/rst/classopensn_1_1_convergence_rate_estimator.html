class ConvergenceRateEstimator

Convergence test for a linearly converging iteration that measures the change between successive iterates.

For such an iteration the error is about change / (1 - rho), with rho the convergence rate, so a change passes a tolerance tol when change < tol (1 - rho).

The rate is estimated as the larger of the last two ratios of successive changes, so that one unusually small ratio of an irregularly converging (for example, accelerated) iteration does not end it early; it is zero for the first change. A relative change below the round-off level kRoundoffRelativeChange always passes.

An accelerated iteration can also take a single step that barely changes the iterate while its error is still large. Converged() therefore tests the larger of the latest change and the change expected from the previous one, rho times the previous change.
