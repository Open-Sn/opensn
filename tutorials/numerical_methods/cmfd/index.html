5.4. CMFD Acceleration

These tutorials show how to use coarse-mesh finite-difference (CMFD) acceleration for k-eigenvalue problems and how its options affect convergence and cost. Each one solves the C5G7 benchmark core with unaccelerated power iteration or with several CMFD settings and compares the eigenvalue, the number of power iterations and transport sweeps, and the wall time. Start with the basics tutorial. The others can be read in any order.

The tutorials use a pin-homogenized model of the C5G7 core, in which every pin cell is one mesh cell, so that each solve takes a few seconds. The benchmark tutorial solves the same core with heterogeneous pins. Run each tutorial with four MPI processes and the pyopensn module. The CMFD user guide describes every option in detail.

The tutorials find the C5G7 cross sections by searching for test/assets/xs/c5g7 in the directory of the script, or the working directory of the notebook kernel, and in its parents. Keep an exported script, or start the notebook kernel, inside an OpenSn checkout, for example in this directory. Elsewhere the tutorial stops before it builds the mesh. To run a tutorial as a script from this directory:

jupyter nbconvert --to script cmfd_basics.ipynb
mpiexec -n 4 python cmfd_basics.py
